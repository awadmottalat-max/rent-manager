# متابعة الإيجارات وإدارة الأملاك (كثيب)

تطبيق ديسكتوب (Electron) لمتابعة العقود والأقساط والتدفقات النقدية وإدارة الأملاك.

## إصدار تحديث
1. عدّل `version` في `package.json` (مثل 1.1.1).
2. `git tag v1.1.1 && git push --tags`
3. يبني GitHub Actions ملف `Setup.exe` وينشره في Releases، ويتحدّث التطبيق تلقائيًا عند المستخدمين.

## الإصدار 1.4.0
- **الشقق المتاحة للإيجار**: صفحة مستقلة، وعدّاد في لوحة التحكم وجدول بعدد المتاح لكل مشروع، وأعمدة الإشغال في المشاريع.
- **المستحقات** و**التدفقات النقدية** صفحتان منفصلتان (المتوقع مقابل المحصَّل فعليًا).
- تسجيل الدفعة بتاريخ التحصيل وفترة الاستحقاق (من/إلى) وطباعة **سند قبض** بشعار كثيب (بدون فترة الاستحقاق).
- **اتفاقيات التأجير** الثلاثية (مالك/مستأجر/المشغّل) برسوم إدارة بنسبة أو مبلغ مقطوع ورسوم عقد مع الضريبة.
- **التحليل المالي** للدفعات المسددة (الضريبة 15% على الإدارة والخدمات ورسوم العقد فقط) مع الربط بالاتفاقية وتعديل يدوي، دون أي بيانات آيبان.

## الإصدار 1.5.0
- العقود المنتهية: صفحة مستقلة، قرار «تجديد» أو «انتهاء الإيجار»؛ الوحدة المنتهية لا تُحسب متاحة حتى انتهاء الإيجار.
- صفحة التقارير: داشبورد، كشف حساب مالك ومستأجر، تقارير جدولية؛ تصدير Excel وطباعة وPDF لكل التقارير.
- العقد الجديد: اختيار الوحدة من وحدات المشروع مع تعبئة المالك، ورقم عقد منصة إيجار.
- التحليل المالي: دعم عقد سابق/يدوي. المشاريع والوحدات: تبويب بفلاتر.
- سند القبض بتصميم كثيب (A5 أفقي، توقيع المحاسب فارغ).
- مظهر أكثر فخامة: أيقونات، لوحة ترحيب، بحث سريع، شاشة بداية.

## الإصدار 1.6.0
- سند القبض مطابق للنموذج (A5 أفقي) مع شرح تلقائي: «إيجار شقة…» للمبلغ الكامل و«دفعة من إيجار شقة…» للجزئي.
- نموذج العقد: الفترة أولًا وحساب النهاية تلقائيًا، حقول إلزامية، جدول الأقساط، فلتر الوحدات وإضافة وحدة جديدة.
- طريقة الدفع «منصة إيجار».
- صفحتا الملاك والمستأجرين مع الإضافة والتعديل، وفلاتر الأسماء في التقارير.
