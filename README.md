## 1.9.1
- إصلاح: فلاتر صفحة العقود (البطاقات والقائمة) لم تكن تعمل بعد 1.9.0؛ تعمل الآن.
- «العقود المنتهية» صارت للمنتهية التي تنتظر قرارًا فقط. المجددة والمُنهاة تخرج منها نهائيًا وتُحفظ في فلتر «الأرشيف» بصفحة العقود، ولا تظهر في «كل العقود الحالية» (إلا عند البحث).
- زر «تراجع عن الإنهاء» في تفاصيل العقد.
- لوحة التحكم: عدد العقود المنتهية = بانتظار القرار فقط.

## 1.9.0
- إصلاح: تعديل بيانات العقد لم يكن يُحفظ (خطأ برمجي صامت). صار يُحفظ، وعند تغيير المالك أو المستأجر أو رقم الوحدة يظهر خيار «تطبيق التغيير على الكل».
- صفحة «الشقق والوحدات»: بطاقات الملخص (متاحة، مؤجرة، بانتظار القرار، خارج الإيجار، الإجمالي) قابلة للنقر وتفتح تفاصيل كل حالة. وكذلك بطاقات العقود والعقود المنتهية والمشاريع والوحدات وجدول لوحة التحكم.
- «إزالة» وحدة من المتاحة (استلمها المالك أو لا يرغب بتأجيرها) مع السبب والتاريخ، و«إعادة للمتاحة»، و«+ إضافة وحدة».
- صفحة العقود: شريط حالات بالأعداد (سارية، متأخرة، منتهية بانتظار قرار، مجددة، أُنهي إيجارها…).
- العقد الذي اتُّخذ فيه قرار (تجديد أو إنهاء) يختفي من التجديدات والعقود المنتهية (بانتظار القرار)، ويظهر في حالته الجديدة فقط. اكتشاف التجديد صار أدق.
- النقر خارج أي نافذة يغلقها (النماذج التي فيها بيانات غير محفوظة تطلب نقرة ثانية).
- فحص سلامة البيانات من الإعدادات: وحدات مكررة، عقود مكررة، تداخل عقود، مع دمج الوحدات المكررة.

## 1.8.0

- العقد الجديد: بداية ونهاية الإيجار (وفترة العقد) في سطر واحد.
- دورة الدفع مرنة: شهري، ربع سنوي، نصف سنوي، سنوي، دفعة واحدة، أو مخصص (كل N شهر / عدد دفعات). وفترة العقد من شهر إلى 11 شهرًا أو مخصصة بعدد أشهر.
- حقل التاريخ الجديد (يوم / شهر بالاسم / سنة) في كل البرنامج بدل مدخل المتصفح المربك، ويقبل الأرقام العربية وزر «اليوم».
- إنهاء العقد (اتفاق الطرفين…) من قائمة العقود وتفاصيل العقد، مع تاريخ الإنهاء والسبب وخيار إسقاط المتبقي.
- تأجير وحدة عليها عقد قائم: خيار إنهاء العقد السابق تلقائيًا بتاريخ محدد.
- المرفقات في العقود والدفعات والإنهاء والملاك والمستأجرين والمشاريع والوحدات والاتفاقيات والتحليل المالي. الملفات تُنسخ إلى مجلد «attachments» داخل مجلد بيانات البرنامج.

# متابعة الإيجارات وإدارة الأملاك (كثيب)

تطبيق ديسكتوب (Electron) لمتابعة العقود والأقساط والتدفقات النقدية وإدارة الأملاك.

## إصدار تحديث
1. عدّل `version` في `package.json` (مثل 1.1.1).
2. `git tag v1.1.1 && git push --tags`
3. يبني GitHub Actions ملف `Setup.exe` وينشره في Releases، ويتحدّث التطبيق تلقائيًا عند المستخدمين.

## الإصدار 1.4.0
- **الشقق المتاحة للإيجار**: صفحة مستقلة، وعدّاد في لوحة التحكم وجدول بعدد المتاح لكل مشروع، وأعمدة الإشغال في المشاريع.
- **المستحقات** و**التدفقات النقدية** صفحتان منفصلتان (المتوقع مقابل المحصَّل فعليًا).
- تسجيل الدفعة بتاريخ التحصيل وفترة الاستحقاق (من/إلى) وطباعة **سند قبض** بشعار كثيب (بدون فترة الاستحقاق).
- **اتفاقيات التأجير** الثلاثية (مالك/مستأجر/المشغّل) برسوم إدارة بنسبة أو مبلغ مقطوع ورسوم عقد مع الضريبة.
- **التحليل المالي** للدفعات المسددة (الضريبة 15% على الإدارة والخدمات ورسوم العقد فقط) مع الربط بالاتفاقية وتعديل يدوي، دون أي بيانات آيبان.

## الإصدار 1.5.0
- العقود المنتهية: صفحة مستقلة، قرار «تجديد» أو «انتهاء الإيجار»؛ الوحدة المنتهية لا تُحسب متاحة حتى انتهاء الإيجار.
- صفحة التقارير: داشبورد، كشف حساب مالك ومستأجر، تقارير جدولية؛ تصدير Excel وطباعة وPDF لكل التقارير.
- العقد الجديد: اختيار الوحدة من وحدات المشروع مع تعبئة المالك، ورقم عقد منصة إيجار.
- التحليل المالي: دعم عقد سابق/يدوي. المشاريع والوحدات: تبويب بفلاتر.
- سند القبض بتصميم كثيب (A5 أفقي، توقيع المحاسب فارغ).
- مظهر أكثر فخامة: أيقونات، لوحة ترحيب، بحث سريع، شاشة بداية.
